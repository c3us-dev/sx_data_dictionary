
# sx_data_dictionary

Tools for digesting and working with SX Data Dictionary compiled HTML help files.

This repo supports two workflows:

1) **Primary pipeline (package CLI):** HTML → JSON dictionary → annotations → SQLite (existing tooling)
2) **Simple generator (single script):** HTML → **Markdown + JSONL** (Ray’s `build_dictionary.py`)

---

## ⚙️ Prerequisites

### For CHM decompilation (choose one)

**Windows (recommended if you already use it):**

- **hh.exe** (Microsoft HTML Help Workshop) for command-line decompilation
- Ensure `hh` is on your `PATH`

**WSL / Ubuntu:**

- `libchm-bin` (provides `extract_chmLib`)

### For Python tooling

- **Python** 3.9+
- **uv** (recommended) for dependency management

---

## 📦 Directory Structure

```text
sx_data_dictionary/

````

## ✅ Step 1 — Decompile the CHM into HTML

### Windows (hh.exe)

1. Drop your `sxdicthlp.chm` into `data/chm/`
2. Decompile to `data/htm/`:

```powershell
hh -decompile .\data\htm\ .\data\chm\sxdicthlp.chm
```

### WSL / Ubuntu (extract_chmLib)

1. Drop your `sxdicthlp.chm` into `data/chm/`
2. Install extractor + decompile:

```bash
sudo apt update
sudo apt install libchm-bin
extract_chmLib ./data/chm/sxdicthlp.chm ./data/htm
```

## ✅ Step 2 — Simple generator (Ray’s script): HTML → Markdown + JSONL

This is a lightweight one-file workflow for producing:

- `data/json/sx_data_dictionary.md`
- `data/json/sx_data_dictionary.jsonl`

### How it works

`build_dictionary.py` reads from:

- `./data/htm` (must contain `modlist.htm`, module pages like `ictbl.htm`, table pages like `icsdtbl.htm`, field pages, etc.)

It parses:

- module list from `modlist.htm`
- tables from each module page
- columns + formats from table pages
- field metadata (Help/Description/etc.) from field pages

### Install deps with uv

From the repo root:

```bash
# only if you don’t already have a uv / pyproject setup
uv init

# ensure dependency is present
uv add beautifulsoup4
```

### Run it

From the repo root:

```bash
uv run python build_dictionary.py
```

### Outputs

Written to:

- `data/json/sx_data_dictionary.md`
- `data/json/sx_data_dictionary.jsonl`
